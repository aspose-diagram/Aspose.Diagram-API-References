## ContainerProperties.ContainerStyle property

ContainerStyle

```csharp
public int ContainerStyle { get; set; }
```

## Remarks

The value of the msvSDContainerStyle cell. Microsoft Visio itself only stores this number; the visual appearance is calculated by the container master's formulas when the document is opened in Visio, so no shape re-creation is required on change.
