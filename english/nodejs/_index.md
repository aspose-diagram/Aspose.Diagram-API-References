The API provides a comprehensive set of classes in the aspose.diagram namespace for loading, manipulating, and saving Visio files (VSD, VSDX, VSS, VST). Developers can work with shapes, connectors, pages, styles, and custom properties, and can export diagrams to formats such as PDF, SVG, PNG, and HTML. All functionality is organized under the single aspose.diagram namespace, making it straightforward to locate and use the required classes.
