Developers can programmatically generate, modify, and export Visio files (VSD, VSDX, VSS, VST) as well as convert them to PDF, SVG, PNG, and other popular formats. The API supports a full range of Visio shapes, connectors, and page properties, allowing precise control over diagram content. Functionality is organized into the aspose.diagram namespace for core diagram operations and the Global namespace for utility classes and constants.

## Namespaces

| Namespace | Description |
| --- | --- |
| [aspose.diagram](./aspose.diagram/) | The aspose.diagram namespace provides classes and enums for creating, editing, and rendering Microsoft Visio diagrams in Node.js via Java. |
| [Global](./global/) | The Global namespace groups fundamental enums and utility types used across Aspose.Diagram for Node.js via Java. |
