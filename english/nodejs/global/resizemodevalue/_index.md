## ResizeModeValue

Utility class containing constants. Specifies the current resize behavior setting for the shape when contained in a group.

## Values

| Name | Description |
| --- | --- |
| USE_GROUP_SETTING | Use group's setting |
| REPOSITION_ONLY | Reposition only. |
| SCALE_WITH_GROUP | Scale with group. |
| UNDEFINED | Undefined. |
