## XJustifyValue

Utility class containing constants. The x-offset of the smart tag button relative to the point defined by the X and Y elements.

## Values

| Name | Description |
| --- | --- |
| LEFT_JUSTIFIED | Left justified (the default). |
| CENTERED | Centered. |
| RIGHT_JUSTIFIED | Right justified. |
| UNDEFINED | Undefined. |
