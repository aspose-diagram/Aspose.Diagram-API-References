## DrawingScaleTypeValue

Utility class containing constants. Specifies the type of drawing scale to use for a page.

## Values

| Name | Description |
| --- | --- |
| NO_SCALE | No scale. |
| ARCHITECTURAL_SCALE | Architectural scale. |
| CIVIL_ENGINEERING_SCALE | Civil engineering scale. |
| CUSTOM_SCALE | Custom scale. |
| METRIC_SCALE | Metric scale. |
| MECHANICAL_ENGINEERING_SCALE | Mechanical engineering scale. |
| UNDEFINED | Undefined. |
