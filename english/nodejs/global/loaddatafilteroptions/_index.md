## LoadDataFilterOptions

Utility class containing constants. Represents the options to filter data when loading diagram from template.

## Values

| Name | Description |
| --- | --- |
| ALL | Load all |
| DOCUMENT_PROPERTIES | Load document properties |
| VBA | Load VBA projects |
| SOLUTION_XML | Load SolutionXML |
| FONT | Load Font |
| FOREGROUND_PAGE | Load Page foreground |
