## ConFixedCodeValue

Utility class containing constants. Determines when a connector reroutes.

| --- | --- |

| REROUTE_NEEDED | Reroute as needed. |
| NEVER_REROUTE | Never reroute. |
| REROUTE_ON_CROSSOVER | Reroute on crossover. |
| RESERVED_1 | Reserved for internal use only. |
| RESERVED_2 | Reserved for internal use only. |
| RESERVED_3 | Reserved for internal use only. |
