## PdfCompliance

Utility class containing constants. Specifies the PDF compliance level to output file.

## Values

| Name | Description |
| --- | --- |
| PDF_15 | The output file will be PDF 1.5 compliant. |
| PDF_A_1_A | The output file will be PDF/A-1a compliant. |
| PDF_A_1_B | The output file will be PDF/A-1b compliant. |
