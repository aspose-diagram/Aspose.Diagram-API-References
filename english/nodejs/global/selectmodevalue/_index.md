## SelectModeValue

Utility class containing constants. Specifies how the user selects a group shape and its members.

## Values

| Name | Description |
| --- | --- |
| GROUP_SHAPE_ONLY | Select the group shape only. |
| GROUP_SHAPE_FIRST | Select the group shape first. |
| MEMBERS_GROUP_FIRST | Select the members of the group first. |
| UNDEFINED | Undefined. |
