## PrintPageOrientationValue

Utility class containing constants. Determines whether the page is printed in portrait or landscape orientation.

## Values

| Name | Description |
| --- | --- |
| SAME_AS_PRINTER | Same as printer. |
| PORTRAIT | Portrait. |
| LANDSCAPE | Landscape. |
| UNDEFINED | Undefined. |
