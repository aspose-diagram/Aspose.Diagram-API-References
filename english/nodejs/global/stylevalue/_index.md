## StyleValue

Utility class containing constants. Specifies the character formatting applied to a range of text in the shape's text block.

## Values

| Name | Description |
| --- | --- |
| BOLD | Bold. |
| ITALIC | Italic. |
| UNDERLINE | Underline. |
| SMALL_CAPS | Small caps. |
| UNDEFINED | Undefined. |
