## HorzAlignValue

Utility class containing constants. Specifies the horizontal alignment of text in the shape's text block.

## Values

| Name | Description |
| --- | --- |
| LEFT_ALIGN | Left align. |
| CENTER | Center. |
| RIGHT_ALIGN | Right align. |
| JUSTIFY | Justify. |
| FORCE_JUSTIFY | Force justify. |
| UNDEFINED | Undefined. |
