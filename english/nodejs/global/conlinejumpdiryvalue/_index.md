## ConLineJumpDirYValue

Utility class containing constants. Determines the line jump direction for line jumps occurring on a vertical segment of a dynamic connector.

## Values

| Name | Description |
| --- | --- |
| PAGE_DEFAULT | Page default. |
| LEFT | Left. |
| RIGHT | Right. |
| UNDEFINED | Undefined. |
