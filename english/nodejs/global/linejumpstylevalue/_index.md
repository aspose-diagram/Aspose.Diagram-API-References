## LineJumpStyleValue

Utility class containing constants. Specifies the line jump style for all connectors on the drawing page that don't have a local line jump style.

## Values

| Name | Description |
| --- | --- |
| DEFAULT | Default. |
| ARC | Arc. |
| GAP | Gap. |
| SQUARE | Square. |
| SIDES_2 | 2 Sides. |
| SIDES_3 | 3 Sides. |
| SIDES_4 | 4 Sides. |
| SIDES_5 | 5 Sides. |
| SIDES_6 | 6 Sides. |
| SIDES_7 | 7 Sides. |
| UNDEFINED | Undefined. |
