## OutputFormatValue

Utility class containing constants. Specifies the output format for a drawing.

## Values

| Name | Description |
| --- | --- |
| DEFAULT_PRINT | Default. Print. |
| POWER_POINT_SLIDE_SHOW | PowerPoint slide show. |
| HTML_OR_GIF_OUTPUT | HTML or GIF output. |
| UNDEFINED | Undefined. |
