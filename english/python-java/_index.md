The API lets you programmatically build, edit, render, and convert Microsoft Visio files (VSD, VSDX, VDX, VSS, VST) while preserving shapes, connectors, stencils, and page settings. It supports export to PDF, SVG, PNG, XPS and other common formats. All functionality is organized under the asposediagram.api namespace, which houses the core Diagram class and related types.
