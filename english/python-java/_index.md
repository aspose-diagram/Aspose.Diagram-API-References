The library is organized under a single namespace, asposediagram.api, which houses the core Diagram class and related types for loading, manipulating, and saving Visio files. Developers can work with VSD, VSDX, VDX, VSS, VST, and VTX formats, access shape, page, and connector properties, and export diagrams to PDF, SVG, and common image formats. All functionality is exposed through Pythonic methods that internally invoke the underlying Java SDK, providing seamless integration in Python projects.
