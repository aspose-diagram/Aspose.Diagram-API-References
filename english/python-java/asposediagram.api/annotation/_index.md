## Annotation class

Contains elements that contain information about comments inserted into a document page.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [ShapeID](./shapeid/) | int | The shape ID of the comment. |
| [IX](./ix/) | int | The zero-based index of the element within its parent element. |
| [Del](./del/) | int | A flag indicating whether the element has been deleted locally. A value of 1 indicates that the element was deleted loca |
| [X](./x/) | DoubleValue | The x-coordinate of the comment marker in page coordinates. |
| [Y](./y/) | DoubleValue | The y-coordinate of the comment marker in page coordinates. |
| [ReviewerID](./reviewerid/) | IntValue | Contains the ID number of the reviewer adding markup to the document. |
| [MarkerIndex](./markerindex/) | IntValue | Specifies the index number assigned to a comment marker. |
| [Date](./date/) | DateValue | specifies when a comment was created |
| [EditDate](./editdate/) | DateValue | Specifies when a comment was last changed |
| [Comment](./comment/) | Str2Value | Contains the comment text in string format for a shape. |
| [LangID](./langid/) | IntValue | Indicates the locale ID (LCID) of the language in which the cell formula, text, custom property, or comment was entered. |
