## ContainerTypeValue enumeration

Utility class containing constants. May be one of the following values: Document, Page, or Master. Only relevant when WindowType is specified as Drawing or Sheet.

## Values

| Name | Description |
| --- | --- |
| DOCUMENT | Document. |
| PAGE | Page. |
| MASTER | Master. |
| STYLE | Master. |
| UNDEFINED | Undefined. |
