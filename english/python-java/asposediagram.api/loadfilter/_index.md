## LoadFilter class

Represents the filter that provides options for loading data when loading diagram from template.

```python
LoadFilter()
```

Constructs one LoadFilter with default filter options LoadDataFilterOptions.All.

## Properties

| Name | Type | Description |
| --- | --- | --- |
| [LoadDataFilterOptions](./loaddatafilteroptions/) | int | The filter options to denote what data should be loaded. The value of the property is LoadDataFilterOptions integer cons |
