## Group class

Contains elements that control how you add shapes to a group, move members of a group, and select groups.

| Name | Type | Description |
| --- | --- | --- |
| [Del](./del/) | int | A flag indicating whether the element has been deleted locally. A value of 1 indicates that the element was deleted loca |
| [SelectMode](./selectmode/) | SelectMode | Specifies how the user selects a group shape and its members. |
| [DisplayMode](./displaymode/) | DisplayMode | When it is contained in a Group element, the DisplayMode element specifies how a group shape and its members are display |
| [IsDropTarget](./isdroptarget/) | BoolValue | Specifies whether the group allows a shape to be added to it when the shape is dropped on the group. |
| [IsSnapTarget](./issnaptarget/) | BoolValue | Specifies whether snapping to a group or to shapes within the group is enabled. |
| [IsTextEditTarget](./istextedittarget/) | BoolValue | Specifies how to assign text to a group. |
| [DontMoveChildren](./dontmovechildren/) | BoolValue | Specifies whether you can drag shapes in a group by using the mouse. |
