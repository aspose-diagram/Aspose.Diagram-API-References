## LineAdjustFromValue enumeration

Utility class containing constants. Specifies which dynamic connectors to space apart if they route on top of each other.

## Values

| Name | Description |
| --- | --- |
| UNRELATED_LINES | Unrelated lines. |
| ALL_LINES | All lines. |
| NO_LINES | No lines. |
| ROUTING_STYLE_DEFAULT | Routing style default. |
| UNDEFINED | Undefined. |
