## PrintProps class

Contains elements that control how the drawing page is formatted (appears) on the printer page.

| Name | Type | Description |
| --- | --- | --- |
| [Del](/python-java/asposediagram.api/printprops/del/) | int | A flag indicating whether the element has been deleted locally. A value of 1 indicates that the element was deleted loca |

| [PageRightMargin](/python-java/asposediagram.api/printprops/pagerightmargin/) | DoubleValue | Specifies the margin at the right of the printed page. |
| [PageTopMargin](/python-java/asposediagram.api/printprops/pagetopmargin/) | DoubleValue | Specifies the margin at the top of the printer page. |
